# Methods of Implementing Network Interface in IoT Modules

## Overview

The aim of this thesis was to provide readers with an overview of IoT modules, the way the network interfaces operate, available hardware components to enable network communication for microcontrollers, and to provide an example implementation of WiFi and Ethernet network interface implementation using STM32 microcontroller.

## Chapters

The thesis consists of the following chapters:

- Overview of the thesis
- Internet of Things
- TCP/IP stack
- Practical implementation of the network interface
- Discussion and conclusions
